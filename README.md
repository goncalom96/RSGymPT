RSGymPT Application

Description: 
- First project developed under Cegid Primavera's Re_Start programme.
- RSGymPT is an application developed to offer a personal trainer service at home.

Features:
- CRUD Operations for users, personal trainers, and home session requests.
- Role-based Access for different user levels (clients and admins).
- Session Management for scheduling and tracking personal training sessions.

Technical Specifications:
- IDE: Visual Studio 2019
- Framework: .NET Framework 4.7.2
- Project Structure:
  -> Class Library (DAL) and Console Application (Client side)
- Languages and Technologies: 
  -> Backend: C#, Entity Framework (Code-First)
- Architecture: Object-Oriented Programming (OOP)
- Database: SQL Server 2019

How to Use:
1) Clone the Repository;
2) Set Up the Database:
- Open the project in Visual Studio;
- In the Package Manager Console:
  -> Select "RSGymPT_DAL" as the default project;
  -> Type the following command:
    - update-database
3) Run the Application.
